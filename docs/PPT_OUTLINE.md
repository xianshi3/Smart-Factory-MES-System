## P2 一句话痛点（行业场景价值）
- 离散车间设备多、数据分散：传感器 / 告警 / 工单 / 维修手册"各自为政"
- 排障靠资深工程师经验，新人上手慢，异常响应滞后 → 停机损失
- 一句话结论：让一线人员用自然语言，一句话完成"诊断 + 处置建议 + 建单"闭环
- 配图：告警中心截图或痛点示意图

## P3 目标用户与场景

## P5 Agent 架构（Agent 能力，重点页）
