# 简历项目描述(模块详情版)

---

## 带模块详情版

```
技术实现：
负责6大微服务(认证、工单、工艺、质量、设备、API网关)架构设计与开发，Spring Cloud Gateway统一网关路由
基于Vue3+TypeScript+Composition API开发17个前端模块(工单管理、工艺配置、质量检验、设备监控、生产看板、报警管理、用户管理、角色权限等)，Pinia状态管理，Element Plus组件库，集成ECharts数据可视化
集成JWT+Spring Security实现RBAC权限控制，支持菜单级和按钮级权限，采用Redis实现Token存储和分布式Session
采用Redis缓存热点数据(如工艺参数、产品BOM)，MyBatis-Plus LambdaQueryWrapper动态查询优化
```
