# MES设备模拟器 (WPF)

## 简介

WPF 桌面设备模拟器，用于模拟 MES 系统设备数据并推送到后端，支持批量模拟与生产场景预设，是本地联调设备数据链路的得力工具。

## 功能

- **设备管理**：创建、更新、删除设备；一键清空全部设备；连接 API 后自动加载后端已有设备
- **批量模拟**：复选框选控参与模拟的设备，一键批量创建 N 台并同时动态运行（未勾选任何设备时退化为单台模式）
- **场景预设**：5 种生产场景（正常运行 / 满载生产 / 高温告警 / 突发故障 / 维护停机），联动参数与设备状态
- **实时曲线**：内置 120 点滚动曲线面板，温度/转速实时绘制
- **参数模拟**：温度、速度、压力、功率四参数控制 + 自动波动开关
- **推送频率**：数据上报间隔可调（0.5s ~ 5s）
- **双通道推送**：HTTP（`POST /api/dashboard/device/simulate`）+ MQTT（`mes/device/{deviceCode}/data`），MQTT 失败自动降级仅 HTTP
- **主题切换**：亮色（默认）/ 暗色 SCADA 风格双主题
- **配置持久化**：API/MQTT 地址、参数、频率、场景自动保存到 `%APPDATA%/MESDeviceSimulator/config.json`，重启自动恢复

## 运行

```bash
cd mes-device-simulator-wpf
dotnet run
```

## 使用

1. 启动模拟器（自动探测 API 网关与 EMQX 地址，失败回退默认 localhost）
2. 点击"连接"——自动连接后端 API 与 MQTT Broker，状态栏显示"已连接 API + MQTT"即双链路就绪
3. 在设备列表中勾选要参与模拟的设备（或新建/批量创建）
4. 选择生产场景（可选），调整推送频率
5. 点击"开始模拟"启动数据推送，实时列表与曲线面板同步刷新

## 数据链路

```
模拟器 ──MQTT──▶ EMQX ──▶ .NET设备网关 ──Kafka──▶ 看板服务 ──WebSocket──▶ 前端
   └──────HTTP───────────────────────▶ 看板服务（直连兜底）
```

## 技术

- .NET 8 + WPF
- MQTTnet 4.3.6（MQTT 发布，QoS 1，自动重连 5 次 × 5s）
- HttpClient 调用后端 REST API
- DispatcherTimer 定时推送数据
- Newtonsoft.Json 配置序列化持久化
